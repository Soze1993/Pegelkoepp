<objective>
Track the "Naturkranz" (a Kranz thrown with a single ball — rare, triggers the tour schnapps round) per player:
a shared button in the input view of every game type records it for a chosen player, a mis-tap can be removed,
a past Naturkranz can be added from the player profile (Nachtragen), and the count per player appears in the
stats API, the Statistik tab, the player profile and the per-evening "Spieler des Abends" table.

Purpose: Members want this rare event counted per player. It is independent of scoring — it must never change a
throw value, score, turn order or game result of any game type.

Output: `naturkranz` table (idempotent migration), `server/routes/naturkranz.js` (+ tests), `naturkranz_count` in
`GET /api/stats` and `GET /api/abende/last-summary`, and the UI in `public/index.html`.

Scope boundaries (not part of this item):
- Entering Mad's past Naturkranz on the VPS is a separate manual step after deploy. This plan only makes it possible
  (profile section "+ Nachtragen", or one SQL INSERT).
- The TV screen (`public/tv.html`, `public/tv.js`) is not changed.
- No game-type module (`server/game-types/*`), no `throws` row and no game state is touched.

Coverage of the three requested requirements (nothing deferred):
- R1 persistence + authenticated add/remove API + recording outside a game: Task 1 (table, POST) and Task 2 (GET, DELETE, date branch).
- R2 shared in-game button with confirmation, undo and Socket.io broadcast: Task 1 (button, confirm dialog, broadcast) and Task 2 (remove).
- R3 statistics (stats API, Statistik tab, profile, per-evening summary): Task 2 (profile section with count) and Task 3.
</objective>

<!-- New contract created by this plan. Implement exactly this. -->
```
Table naturkranz
  id         INTEGER PRIMARY KEY AUTOINCREMENT
  player_id  INTEGER NOT NULL REFERENCES players(id)
  game_id    INTEGER NULL     REFERENCES games(id)
  abend_id   INTEGER NULL     REFERENCES abende(id)
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime'))

POST   /api/naturkranz      session   body { player_id:int, game_id?:int, date?:'YYYY-MM-DD' }
         201 { id, player_id, game_id|null, abend_id|null, created_at }
         400 invalid input   401 no session   404 player or game not found
GET    /api/naturkranz      session   query player_id?, game_id?
         200 [ { id, player_id, player_name, player_emoji, game_id, type_key, abend_id, abend_name, created_at } ]  newest first
DELETE /api/naturkranz/:id  session   200 { ok:true }   400 invalid id   401   404 not found

Socket.io, io.emit to all clients:
  'naturkranz:changed' { action:'added',   id, player_id, player_name, game_id, abend_id, created_at }
  'naturkranz:changed' { action:'removed', id, player_id, game_id, abend_id }

GET /api/stats                players[i].naturkranz_count : integer (0 when none)
GET /api/abende/last-summary  players[i].naturkranz_count : integer (0 when none)
```
abend_id and created_at are always derived on the server; client-supplied values for them are ignored.
