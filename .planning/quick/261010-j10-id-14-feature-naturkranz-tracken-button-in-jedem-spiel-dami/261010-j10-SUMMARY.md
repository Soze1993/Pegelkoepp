## Final API contract

- `POST /api/naturkranz` (session) body `{ player_id, game_id? | date? }` -> 201 `{ id, player_id, game_id, abend_id, created_at }`; 400 invalid input (including `invalid date`, `game_id and date are mutually exclusive`, `player not in game`), 401 without session, 404 player/game not found. `abend_id` and `created_at` are derived on the server.
- `GET /api/naturkranz?player_id=&game_id=` (session) -> list newest first (`id, player_id, player_name, player_emoji, game_id, type_key, abend_id, abend_name, created_at`), LIMIT 500; 400 on invalid filters.
- `DELETE /api/naturkranz/:id` (session) -> `{ ok: true }`; 400 invalid id, 404 not found.
- Socket.io (`io.emit`, all clients): `naturkranz:changed` `{ action:'added', id, player_id, player_name, game_id, abend_id, created_at }` and `{ action:'removed', id, player_id, game_id, abend_id }`.
- `GET /api/stats` and `GET /api/abende/last-summary`: `players[i].naturkranz_count` (integer, 0 when none). The summary also lists players whose only entry that evening is a Naturkranz (games_played 0, wins 0).

New frontend functions (public/index.html): `appendNaturkranzButton`, `openNaturkranzModal`, `nkLoadEvents`, `renderNaturkranzModal`, `nkSubmit`, `nkRemove`, `nkRefreshVisible`, `nkFmtDate`, `renderSpNaturkranz`, `spNkAdd`, `onNaturkranzChanged`. Modal `m-nk`, container `sp-nk` in the profile.

## Nachtragen auf der VPS (Mad)

a) UI: Spieler tab, open Mad's profile, set the date of the Kegelabend in the "Naturkranz" section, tap "+ Nachtragen", confirm. The entry is linked to the abend of that day if one exists. Wrong entries can be removed with "Entfernen".

b) SQL fallback (one INSERT, player id and date adjusted):
```sql
INSERT INTO naturkranz (player_id, abend_id, created_at)
VALUES (<mad_player_id>, <abend_id or NULL>, '2026-04-01 00:00:00');
```
