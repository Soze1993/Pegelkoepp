<objective>
Feedback ID 18 (Feature): in TV mode, show the display name of the currently running game in the top-left corner, in the same row that already lists the KDA-Gewinner and BK-Verlierer of the evening.

Purpose: from the bowling lane nobody can tell which game the TV is showing. The top row is the one place that is visible in every game screen.

Output: a fixed top bar on the TV page (game name left, existing highlights right), fed by the existing `GAME_NAMES` map and updated by the existing socket events; the KDA bracket reserves the same top band as the other renderers; the old centered game-name header is removed so each screen shows the name exactly once; a node:test harness proves it for all nine game types.

Location correction (verified at planning time): the TV mode is NOT in `public/index.html`. It is the separate page served at `/tv` — `public/tv.html` (markup + CSS) and `public/tv.js` (all TV renderers). `public/index.html` is not touched by this plan.
</objective>

Design decisions for this item (planner discretion — no CONTEXT.md exists for quick items):
- Same row is guaranteed structurally: one fixed flex bar holds both the name and the highlights, instead of two independently positioned elements.
